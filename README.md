# Portfolio — Blud

A personal portfolio site with dark and light themes, built with React, Redux Toolkit and Material UI.

**Live demo:** [latestwork.netlify.app](https://latestwork.netlify.app)

## Features

- Dark / light theme stored in Redux Toolkit
- Experience section with company tabs
- Latest work grid, skills and contact sections
- Responsive layout with a hamburger menu and toast notifications

## Tech stack

React · Redux Toolkit · Material UI · Sass (CSS Modules) · React Router · Axios

## Getting started

```bash
npm install
npm start         # http://localhost:3000
npm run build     # production build → build/
```

## Project structure

```
src/
├─ Components/   # Header, Home, About, Experience, Work, Contact, Footer
├─ Routes/       # route configuration
└─ Store/        # Redux store and theme slice
```
